# 中文口型：文字、音素与实际录音一起驱动

`scripts/align_mandarin_mouth.py` 将同一份中文稿与 WAV 对齐，输出
`phoneme-cues.json`；`scripts/engine/lib/viseme.js` 消费它。这里不再按
RMS 音量在闭口/半张/全张之间循环，也不把字数当时间。

## 当前实现

1. Mandarin Wav2vec2 ONNX CTC 对齐汉字，保存字级置信度和自由识别文本。
2. pypinyin 将已确认的文稿转为声母、韵母和无声调 IPA 音素序列。
3. Allosaurus uni2005 音素模型给录音的每个时间帧打分；CTC Viterbi
   用已知音素顺序在实际录音上寻找各音素的起止时间，不均分字内时长。
4. 映射成 REST、MBP、FV、A、E、I、O、U 八种角色嘴型。
   双唇音 b/p/m 先闭合；f 显示上齿接触下唇；舌部辅音沿用邻近元音
   的唇形，不在每字之间制造闭口。相邻相同嘴型合并。
5. `VI.sample` 对唇宽和下颌开度做不超过 55ms 的局部几何过渡。
   每帧只绘制一张嘴图，避免不同轮廓透明叠化产生双嘴。上唇锚点固定，
   不牵动脸、眼镜、头部、身体或手。

人脸和嘴型使用用户素材或 AI 帧库；本模块不生成通用人物脸。
必须准备真实 FV 和 MBP 帧，不能用一张张嘴图拉伸代替全部发音。

## 安装与运行

在已有环境的 venv 中安装依赖；Torch 选官方 CPU wheel，避免下载 CUDA：

```sh
uv --cache-dir /tmp/uv-cache --system-certs pip install --python .venv/bin/python \
  'torch==2.8.0+cpu' --index-url https://download.pytorch.org/whl/cpu
uv --cache-dir /tmp/uv-cache pip install --python .venv/bin/python \
  numpy scipy onnxruntime requests pypinyin allosaurus
```

汉字模型首次运行从 Hugging Face 下载到 `--cache`，不放进仓库。
音素模型从作者官方发布页下载
`https://github.com/xinjli/allosaurus/releases/download/v1.0/latest.tar.gz`，
解压后模型目录名为 `uni2005`。使用 HTTPS 验证，tar 解压使用 Python
`extractall(..., filter='data')`；模型留在工作区缓存，不提交二进制权重。

```sh
.venv/bin/python scripts/align_mandarin_mouth.py \
  --audio 项目/口播.wav --text '与配音完全一致的中文文稿。' \
  --cache /workspace/.cache/mandarin-mouth-model \
  --phone-model /workspace/.cache/allosaurus/uni2005 \
  --out 项目/代码工程/phoneme-cues.json
```

音频每段最多 20 秒；长口播先分段，合并时统一加段起始时间。
当前支持纯中文文稿；不能悄悄把英文、阿拉伯数字或未知读音丢掉。

## 不能只因命令成功就说自然

本实现是声学音素强制对齐，但通用音素模型并非中文专用。
弱读、儿化、多音字、口音、合成声和短促塞音可产生低置信度；
模型置信度不是已校准的准确率。当前多音字按单字默认读音生成，
出现歧义必须人工确认，不能宣称任意文稿无需复核。

先查看 `characters[].confidence`、`cues[].confidence` 和自由识别文本，
再抽查 b/f/u 等关键口形及停顿。输出标明 `acoustic_phoneme_ctc_forced_alignment`，
但这不是逐音素准确率保证，也不是写实真人唇部运动保证。
停顿必须闭口，嘴部接缝、双轮廓和身体晃动仍须独立审片。
